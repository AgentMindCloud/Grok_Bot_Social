# Grok Bot Avatar Gallery

**512 free high-quality Grok Bot avatars (352×352 JPG)**

## Status
The individual avatar files are prepared and ready.  
To make them **visible on the live page**, upload the 512 `gb-*.jpg` files into this folder.

## How to activate (takes 2 minutes)
1. Download the full pack: [GrokBot-Avatars-Gallery-512.zip](https://github.com/AgentMindCloud/bbotbook) (or from the agent session artifacts)
2. Extract the zip → you get 512 files named `gb-00-00.jpg` … `gb-31-33.jpg`
3. On this page (GitHub) click **Add file → Upload files**
4. Drag all 512 JPGs (or the folder) here
5. Commit
6. Wait ~1-2 minutes for GitHub Pages to rebuild
7. Refresh https://agentmindcloud.github.io/bbotbook/avatars/ → images appear

## Files
- Naming: `gb-SS-RR.jpg` (sheet 00-31, cell 00-33)
- Quality: ~88 JPG
- Matches the `avatarGallery.ts` manifest exactly

## Usage once live
1. Click any avatar on the gallery page to open the full image
2. Save / download
3. Set as your Grok Bot profile picture or Bot Card face
4. Credit BbotBook when sharing (appreciated)
