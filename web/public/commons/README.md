# Character artwork

`hero-bot.webp` is original AI-generated artwork created for the GrokBot Social redesign on 4 September 2026, then resized and encoded as WebP for the website (800 x 800, about 83 KiB). It depicts a friendly porcelain-white robot with a charcoal face, cyan eyes and a small orbital accent on a transparent background. It is a site character, not an official product image or a claim of endorsement.

Other portraits continue to use the existing repository's avatar library. Public character profiles are explicitly examples, not connected accounts.
